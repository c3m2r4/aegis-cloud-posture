FIRST RUN · CLI REFERENCE

Setup and command guide

Use a read-only cloud identity. AEGIS does not load .env files; configuration is read from the process environment. Never paste secret values into the dashboard, screenshots, or shared logs.

Open guided assessment
1 · INSTALL

Install AEGIS

AEGIS requires Python 3.11 or newer. From the project directory, check Python and pip, then install dashboard and test dependencies.

python --version
python -m pip --version
python -m pip install -e '.[dashboard,test]'
aegis version
2 · CONFIGURE

Select endpoint, region, and database

These are non-secret settings. The default endpoint is local Floci; replace it only with an intended provider endpoint.

export AEGIS_ENDPOINT_URL='http://127.0.0.1:4566'
export AEGIS_REGION='us-east-1'
export AEGIS_DATABASE='./aegis.db'
export AWS_PROFILE='your-read-only-profile'
3 · VERIFY

Check prerequisites

Doctor checks local configuration, SQLite, endpoint reachability, credential resolution, and STS identity. Preflight additionally discovers the verified read operations.

aegis --help
aegis config
aegis doctor
aegis preflight --json
4 · PREVIEW AND SCAN

Review, then confirm

Preview does not contact cloud services. Interactive scans ask for confirmation; scripts must pass --yes.

aegis assess --preview
aegis assess --yes
5 · INVESTIGATE

Review saved results

Replace example IDs with identifiers printed by AEGIS. History and detail commands read SQLite only.

aegis history
aegis show ASSESSMENT_ID
aegis findings ASSESSMENT_ID --outcome FAIL
aegis resources ASSESSMENT_ID
aegis operations ASSESSMENT_ID
6 · COMPARE AND REPORT

Export persisted evidence

aegis compare PREVIOUS_ID CURRENT_ID
aegis report --assessment ASSESSMENT_ID --format markdown
aegis report --assessment ASSESSMENT_ID --format json
SCOPE AND SAFETY

Understand what the results mean

  • Current checks cover local IAM policies, EC2 security-group management ingress, and CloudWatch log retention when the field is returned.
  • Only documented read operations are used. Pagination is disabled until verified; unsupported or errored evidence is never a pass.
  • Preflight is a deliberate cloud-read action. The assessment makes a fresh set of calls after confirmation.
  • Credentials are not entered in the dashboard, displayed by AEGIS, or saved in the assessment database.
  • The local dashboard has no authentication. Keep it bound to loopback and do not expose it to a network.
